# PMfolio: วิธีอ่านข้อมูลและเปรียบเทียบวาระ

สถานะ: active · เจ้าของหลักเกณฑ์ข้อมูลและการคำนวณของ PMfolio · methodology version 2 · ตรวจ snapshot วันที่ 3 ตุลาคม 2026

## เว็บนี้วัดอะไร

PMfolio เป็นสารบัญนายกรัฐมนตรีไทยและเครื่องมืออ่านผลลัพธ์ระดับประเทศระหว่างที่แต่ละคนดำรงตำแหน่ง รูปแบบการ์ดตัวละครและ VS มีไว้ช่วยสำรวจข้อมูล ไม่ใช่ข้อสรุปว่าใครเก่งกว่า ใครเป็นคนทำให้ตัวเลขเปลี่ยน หรือใครควรได้รับเลือกตั้ง

คำที่ใช้กับคะแนนคือ **ดัชนีผลลัพธ์ช่วงวาระ** หรือ **บริบทประเทศในปีที่ดำรงตำแหน่ง** ตามฐานปีที่ใช้ ทั้งสองอย่างบอก **ตำแหน่งในประวัติข้อมูลไทย** ต้องแสดงค่าจริง หน่วย ช่วงปี จำนวนปี สูตร และลิงก์ต้นทางควบคู่กัน คะแนนไม่ใช่ร้อยละที่นโยบายสำเร็จ ไม่ใช่คะแนนทักษะส่วนบุคคล และไม่ใช่เปอร์เซ็นต์ประชาชนที่เห็นด้วย ข้อมูลจริงเพียงปีเดียวคำนวณตำแหน่งในชุดอ้างอิงได้ แต่ต้องติดป้ายและไม่สรุปแนวโน้มจากค่านั้น

ข้อมูลประกอบด้วยสองชั้นที่ต้องแยกกัน:

1. **ผลลัพธ์ที่สังเกตได้ระหว่างวาระ** เช่น GDP เติบโตจริงในปีอ้างอิง ดึงจากชุดข้อมูลที่ระบุแหล่งและรหัสชุดอย่างชัดเจน
2. **ความเชื่อมโยงกับนโยบาย** ต้องมีหลักฐานรายเรื่อง เช่น ตัวบทนโยบาย วันเริ่มใช้ ผลประเมิน และผู้ที่ได้รับผลกระทบ การอยู่ในตำแหน่งระหว่างปีนั้นเพียงอย่างเดียวไม่ใช่หลักฐานเชิงเหตุและผล

เว็บเน้นข้อมูลชั้นที่หนึ่ง รวมทั้งค่าประมาณประวัติศาสตร์ที่มีผู้ผลิตและวิธีวิจัยระบุชัด ยังไม่ใช่งานประเมินนโยบายเชิงเหตุและผลครบทุกนายกฯ การมีค่าจากแหล่งข้อมูลจริงไม่ได้หมายความว่ามีการสำรวจโดยตรงหรือเป็นอิสระทุกปี

## แหล่งข้อมูลและการทำซ้ำ

- [catalog.ts](../src/data/catalog.ts) รวมตัวชี้วัดจาก snapshot สามไฟล์: [indicators.json](../src/data/indicators.json) สำหรับ WDI/WGI, [historical-indicators.json](../src/data/historical-indicators.json) สำหรับ Maddison Project และ [extended-indicators.json](../src/data/extended-indicators.json) สำหรับ V-Dem, อายุขัยประวัติศาสตร์, Lee–Lee, UNDP และ UNESCO UIS/WDI เพิ่มเติม ณ snapshot นี้รวม 26 ตัวชี้วัด
- การดึงข้อมูล World Bank อยู่ที่ [fetch-indicators.py](../scripts/fetch-indicators.py) วิธีสร้าง GDP ย้อนหลังและที่มาอยู่ที่ [historical-data.md](historical-data.md) ส่วนข้อมูลสังคม/การศึกษาที่เพิ่มอยู่ที่ [extended-data.md](extended-data.md) ใช้แหล่งข้อมูลสาธารณะที่เปิดให้ดาวน์โหลดโดยไม่ต้องใช้ credentials
- WDI ใช้ source ID `2` และ WGI ใช้ source ID `3` ระบุ `source.apiUrl`, `source.code`, `source.lastUpdated` ในแต่ละรายการ
- `asOf` เป็นวันที่ดาวน์โหลด snapshot ไม่ใช่วันสิ้นสุดของทุกชุดข้อมูล ปีล่าสุดของแต่ละตัวชี้วัดอ่านจาก `values` เท่านั้น วันที่ของ snapshot ทั้งสามและ `DATA_AS_OF` ใน engine ต้องตรงกัน
- ไม่ปัดค่าจริงที่เก็บใน JSON ก่อนคำนวณ การปัดทศนิยมเป็นเรื่องการแสดงผล
- ไม่เติมค่าปีที่หาย ไม่ลากค่าปีก่อนหรือปีใกล้เคียงมาทับ ไม่ใช้ศูนย์แทนค่าไม่ทราบ และไม่นำค่าคาดการณ์อนาคตมาใช้เป็นผลลัพธ์ที่เกิดขึ้นแล้ว ชุด Lee–Lee ใช้ถึง 2010 และตัดส่วนประมาณล่วงหน้าตั้งแต่ 2015; อายุขัย UN WPP ในชุดเสริมใช้ถึง 2023 ข้อมูลต้นทางบางชุดผ่านการประมาณย้อนหลัง/แบบจำลอง รวมถึง interpolation ของผู้ผลิตตามนิยามที่อธิบายไว้
- ใช้ค่าที่ API ส่งมาใน snapshot เดียวกัน แหล่งข้อมูลอาจปรับย้อนหลัง ซึ่งทำให้ค่าหรือ percentile เปลี่ยนได้ การเลือก `--as-of` ย้อนหลังไม่สามารถกู้ data vintage เก่าจาก API ปัจจุบันได้ สคริปต์จึงปฏิเสธ source ที่อัปเดตหลังวันที่ร้องขอ
- สคริปต์ปฏิเสธข้อมูลที่รหัสหรือประเทศไม่ตรง ค่าที่ไม่ใช่ตัวเลข ปีซ้ำ pagination ที่ยังไม่ครบ และความผิดพลาดเครือข่ายหลังลองใหม่ตามจำนวนครั้งที่กำหนด ไม่ใช้ snapshot เก่าเงียบ ๆ
- ผลลัพธ์ปกติพิมพ์ JSON ทาง stdout; `--patch` พิมพ์แพตช์สำหรับ apply_patch โดยไม่มีการเขียนไฟล์เอง ตรวจ diff ก่อนใช้แพตช์และดำเนิน release checks ตาม [development.md](development.md)

ตัวอย่างอ่านข้อมูลโดยไม่แก้ไฟล์:

```bash
python3 scripts/fetch-indicators.py --as-of 2026-10-03
```

WDI และ WGI ให้เครดิต World Bank และหน่วยงานเจ้าของข้อมูลต้นทางตาม metadata ของแต่ละตัวชี้วัด ตรวจเงื่อนไข reuse จาก [World Bank Open Data terms](https://www.worldbank.org/en/about/legal/terms-of-use-for-datasets) ส่วน Maddison, V-Dem และชุดที่เผยแพร่ผ่าน OWID ใช้เครดิต/เงื่อนไขของแต่ละแหล่งตามเอกสารเจ้าของชุดข้างต้น โดยข้อมูล V-Dem และค่าที่คำนวณจากชุดนี้ใช้ CC BY-SA 4.0 ไม่อ้างว่า PMfolio เป็นผู้ผลิตสถิติต้นทาง

ผลตรวจแบบเลือก “ทุกวาระ” วันที่ 3 ตุลาคม 2026: มีดัชนีที่อ้างแหล่งข้อมูลได้อย่างน้อยหนึ่งด้าน **32/32 คน** รวม **181/288 ช่องรายด้าน** เทียบกับรุ่นเดิมที่ใช้ 18 ตัวชี้วัดและกำหนดอย่างน้อยสองปีในวาระ ซึ่งมี **11/32 คน และ 61/288 ช่อง** การเพิ่มนี้มาจากทั้งชุดข้อมูลเพิ่มเติม การยอมแสดงข้อมูลปีเดียว และบริบทประเทศสำหรับวาระสั้น จึงไม่ได้แปลว่าคุณภาพหลักฐานเท่ากันทั้ง 32 คนหรือครบทุกด้านแล้ว

การ์ดแสดงสูงสุดสามด้านที่มีดัชนีตามลำดับหมวดที่กำหนด ไม่เลือกสามคะแนนสูงสุด ไม่แสดงช่องที่ขาดเป็นศูนย์ และบอกจำนวนด้านที่มีข้อมูลทั้งหมด หน้าแฟ้มแสดงครบทุกด้านพร้อมข้อจำกัด การเปลี่ยนไปเลือกวาระเฉพาะอาจได้จำนวนด้านน้อยลงหรือไม่มีค่า นายกฯ ที่มีแต่ปีปัจจุบันซึ่งยังไม่สิ้นสุดจะยังไม่มีฐานปีให้คำนวณ

## การจับปีเข้ากับช่วงดำรงตำแหน่ง

ใช้ปีปฏิทินที่สิ้นสุดแล้ว ณ วันที่ `asOf` เท่านั้น ณ snapshot แรกคือไม่เกินปี 2025 แม้พบข้อมูลปี 2026 ใน API ก็ยังไม่นำมาคิด

สำหรับแต่ละปีนับจำนวนวันจริงที่บุคคลอยู่ในช่วงตำแหน่งที่เลือก ถ้าวันครอบคลุม **มากกว่าครึ่งหนึ่งของวันในปีนั้น** จึงจัดปีให้คนนั้น ต้องนับ 366 วันในปีอธิกสุรทินอย่างถูกต้อง วันเปลี่ยนตำแหน่งต้องใช้ช่วงเวลาแบบไม่ทับกันใน engine เพื่อไม่ให้หนึ่งวันถูกจัดให้สองคน

- หนึ่งปีมีเจ้าของได้ไม่เกินหนึ่งคน ถ้าไม่มีใครเกินครึ่งให้ปีนั้นไม่ถูกจัดสรร การเป็นคนที่ครองตำแหน่งมากที่สุดในปีซึ่งมีสามคนยังไม่พอ
- กฎนี้เป็นวิธีจัดหมวดเพื่อหลีกเลี่ยงการให้ GDP ปีเดียวกันแก่หลายคน ไม่ใช่หลักฐานว่าคนนั้นสร้างผลลัพธ์ทั้งปี
- เมื่อดูทุกวาระของคนเดียวกัน ให้นับสหภาพของวันและปีที่ได้รับจัดสรร ไม่รวมปีซ้ำ ผลลัพธ์จึงเป็น “ช่วงที่ดำรงตำแหน่งรวม” ไม่ใช่วาระเดียวต่อเนื่อง
- เมื่อเลือกวาระหนึ่ง ต้องคำนวณจากวันของวาระนั้นเท่านั้น ห้ามใช้ปีจากวาระอื่นที่ผู้ใช้ไม่ได้เลือก
- การเปลี่ยนคณะรัฐมนตรีระหว่างปี การรักษาการ การพักปฏิบัติหน้าที่ และช่วงอำนาจบริหารที่ต่างจากสถานะนายกรัฐมนตรีตามกฎหมายอาจไม่ตรงกับช่วงชีวประวัติ ต้องเปิดดูรายละเอียดช่วงตำแหน่ง แฟ้มบุคคลไม่ได้แปลว่าทุกวันเป็นวันที่ใช้อำนาจจริงทั้งหมด
- การศึกษาใช้ปีการศึกษาที่ต้นทางกำหนด และข้อมูลการคลังอาจเป็นปีงบประมาณ การแสดงค่าภายใต้ปีปฏิทินเป็นการจับตามป้ายปีอ้างอิงของชุดนั้น ไม่ได้ปรับใหม่ให้ตรงวันทำงานของรัฐบาลไทย

ถ้ามีปีที่ผ่านเกณฑ์เกินครึ่งปีอย่างน้อยหนึ่งปี ใช้เฉพาะชุดปีนั้นทุกตัวชี้วัด แม้ตัวชี้วัดบางด้านไม่มีข้อมูลก็ไม่ไปยืมปีอื่นมาทดแทน

**เฉพาะเมื่อไม่มีปีที่ผ่านเกณฑ์เลย** จึงใช้ทางเลือก “บริบทประเทศ”: เลือกปีปฏิทินที่สิ้นสุดแล้วและช่วงตำแหน่งที่เลือกคาบเกี่ยวอย่างน้อยหนึ่งวัน ใช้ค่าทั้งปีจากต้นทาง ไม่คูณแบ่งตามวัน ไม่ใช้ปีก่อนเข้ารับตำแหน่งหรือปีถัดออกไปเพียงเพราะมีข้อมูล ทั้งฐานปีปกติและฐานบริบทห้ามใช้ข้อมูลจากวาระอื่นที่ไม่ได้เลือก

หลายวาระสั้นอาจแสดงข้อมูลประเทศของปีเดียวกันภายใต้ป้ายบริบทได้ แต่ไม่ได้รับการจัดสรรปีนั้นเป็นผลงานของตน ค่า GDP 2025 ที่เห็นในบริบทของวาระสั้นจึงหมายถึงเศรษฐกิจไทยทั้งปี 2025 ไม่ใช่ผลที่คนนั้นสร้างในไม่กี่เดือน

ป้ายฐานข้อมูลของแต่ละตัวชี้วัดใช้ดังนี้:

| ค่า `basis` | ป้าย | เงื่อนไข |
|---|---|---|
| `tenure` | หลายปีในวาระ | มีค่าอย่างน้อย 2 ปีในชุดปีที่ผ่านเกณฑ์เกินครึ่งปี |
| `single-year` | ข้อมูลปีเดียว | มีค่า 1 ปีในชุดปีที่ผ่านเกณฑ์เกินครึ่งปี |
| `country-context` | บริบทประเทศ | ใช้ปีคาบเกี่ยวเพราะไม่มีปีที่ผ่านเกณฑ์เลย ไม่ว่ามีกี่ค่าก็ตาม |
| `none` | ไม่มีข้อมูล | ไม่มีค่าที่ใช้ได้ในชุดปีนั้น |

เมื่อสรุปหลายตัวชี้วัดในหนึ่งด้านหรือหลายด้านในหนึ่งแฟ้ม ใช้ป้ายที่สะท้อนข้อจำกัดมากที่สุดของข้อมูลที่นำมาคำนวณ: บริบทประเทศมาก่อนข้อมูลปีเดียว แล้วจึงหลายปีในวาระ หากมีข้อมูลหลายปีและปีเดียวปนกัน ป้ายระดับแฟ้มใช้ “บางด้านมีข้อมูลปีเดียว” ไม่ทำให้เข้าใจว่าทุกด้านมีความครอบคลุมเท่ากัน

## สูตรดัชนีผลลัพธ์

คำนวณเฉพาะตัวชี้วัดที่ตั้ง `scorable: true` และมี `direction` เป็น `higher` หรือ `lower`

ให้ `T` เป็นชุดค่ารายปีที่ต้นทางเผยแพร่ของประเทศไทยในตัวชี้วัดนั้นจาก snapshot และ `V` เป็นค่าจากชุดปีที่ใช้ตามกฎด้านบน ต้องมี `|V| >= 1` และ `|T| >= 2` จึงคำนวณ percentile ได้ ปีปัจจุบันและค่าที่ไม่ใช่ตัวเลข finite ถูกตัดออก ปีซ้ำที่ขัดแย้งกันถูกถือว่าไม่ทราบ ไม่เลือกค่าหนึ่งเงียบ ๆ

1. ค่าเฉลี่ยของชุดปีที่ใช้ `m = sum(V) / |V|` เป็นค่าเฉลี่ยเลขคณิต ให้น้ำหนักทุกปีที่มีข้อมูลเท่ากัน อัตราเติบโตไม่ได้ทบต้น และไม่ได้ถ่วงตามจำนวนวันภายในปี หากมีค่าเดียว ค่าเฉลี่ยเท่ากับค่านั้นและติดป้ายข้อมูลปีเดียวหรือบริบทตามฐานปี
2. `L` = จำนวนค่าของ `T` ที่ต่ำกว่า `m`; `E` = จำนวนค่าที่เท่ากับ `m`; `N = |T|`
3. Midrank percentile: `p = 100 × (L + 0.5 × E) / N`
4. ถ้า `higher` ใช้ `p`; ถ้า `lower` ใช้ `100 − p`
5. ปัดผลเพื่อแสดงหลังจากคำนวณเสร็จ ค่าดิบยังคงความละเอียดต้นทาง คะแนนเท่ากันหลังปัดไม่ได้แปลว่าค่าจริงเท่ากัน

ตัวอย่างทางคณิตศาสตร์เท่านั้น ไม่ใช่ข้อมูลนายกฯ: ถ้าค่าประวัติมี `[1, 2, 2, 4]` และค่าเฉลี่ยวาระเท่ากับ `2` จะได้ `(1 + 0.5×2)/4 × 100 = 50` ถ้าทุกค่าของชุดเท่ากัน คะแนนจะเท่ากับ 50 แทนการสร้างผู้ชนะจากข้อมูลที่ไม่แตกต่าง

นี่คือการเทียบค่าเฉลี่ยช่วงวาระกับ **การกระจายค่ารายปีของไทย** ไม่ใช่อันดับนายกฯ เทียบกันเอง ไม่ใช่ผลทดสอบนัยสำคัญ และไม่ได้ปรับความยากง่ายของแต่ละยุค ค่าเฉลี่ยหลายปียังมีความผันผวนน้อยกว่าค่ารายปีที่ใช้เป็นฐาน percentile จึงไม่ควรตีความเป็นผลสอบ

ก่อนสรุปดัชนีรายด้าน จัดตัวชี้วัดที่คำนวณได้ตาม `scoreFamily` และเลือก **ทั้งอนุกรมจากแหล่งเดียว** ต่อหนึ่งกลุ่ม โดย `scorePriority` สูงกว่ามาก่อน หากเท่ากันเรียง `id` เพื่อให้ผลแน่นอน ไม่เลือกตามคะแนนที่สูงกว่า และไม่หยิบปีที่ขาดจากอีกแหล่งมาต่อให้ครบ ตัวชี้วัดที่ไม่มี family ใช้ `id` ของตนเป็นกลุ่ม ข้อมูลค่าดิบของชุดที่ไม่ได้เลือกยังเปิดอ่านได้

WDI มี priority 20 ส่วน MPD growth, อายุขัยย้อนหลัง และ V-Dem มี priority 10 ในกลุ่มทางเลือกของตน UNDP ปีการศึกษาอายุ 25+ มี priority 20 และ Lee–Lee อายุ 15–64 มี priority 10 ในกลุ่มการศึกษาสะสม การจัดเป็น family เป็นกติกาป้องกันการให้น้ำหนักซ้ำ ไม่ได้ยืนยันว่าต่างแหล่งมีนิยามหรือค่าดิบเหมือนกัน ชุดหลักที่มีเพียงปีเดียวก็ยังมาก่อนชุดสำรองที่มีหลายปีเมื่อคำนวณได้ และต้องแสดงป้ายปีเดียวตามจริง

ดัชนีรายด้านคือค่าเฉลี่ย percentile ของตัวชี้วัดที่ถูกเลือกจากแต่ละกลุ่ม ให้น้ำหนักเท่ากันและบอกจำนวนชุดที่ใช้ ไม่มีคะแนนรวมทุกด้านเป็นคะแนนบุคคลเดียว ด้านเศรษฐกิจยังมี GDP รวมกับ GDP ต่อคนซึ่งสัมพันธ์กัน จึงไม่อ้างว่าเป็นหลักฐานอิสระสองเท่า

ด้านการคลังตั้งใจไม่มีดัชนี เพราะหนี้ต่ำหรือภาษีสูงไม่ได้มีทิศ “ดี” ที่ถูกต้องในทุกสถานการณ์ แสดงตัวเลขกับบริบทแทน ไม่เติมเรดาร์เป็นศูนย์

## VS: เปรียบเทียบอย่างไรให้ยังอ่านหลักฐานได้

แนวคิดหลักคือ **เลือกสองแฟ้ม เปิดหลักฐานคู่กัน** ใช้สีคนละฝั่ง รูปแบบเลือกตัวละคร และกราฟตัวเลขควบคู่ แต่ไม่ประกาศแชมป์รวมจากคะแนนที่นิยามขึ้นเอง

- เปรียบเทียบตัวชี้วัด `id` เดียวกัน นิยาม/หน่วยเดียวกัน และ snapshot เดียวกันเท่านั้น แสดงปีและป้ายฐานของซ้ายขวาใกล้ตัวเลข แต่ละฝั่งใช้ปีของช่วงตำแหน่งตนเอง ไม่จำเป็นต้องเป็นปีเดียวกัน
- ค่าดิบและส่วนต่างแสดงได้เมื่อทั้งสองฝั่งมีอย่างน้อยหนึ่งค่าของตัวชี้วัดเดียวกัน ดัชนีของข้อมูลปีเดียวหรือบริบทประเทศก็แสดงคู่กันได้พร้อมป้ายข้อจำกัด แต่ไม่ทำให้กลายเป็นข้อสรุปผลของวาระ
- ดัชนีเทียบรายด้านใช้ **intersection ของตัวชี้วัดที่ทั้งสองฝั่งคำนวณดัชนีได้** แล้วเลือกหนึ่งตัวชี้วัดต่อ `scoreFamily` ตาม priority จากชุดร่วมนี้ ทั้งซ้ายและขวาต้องใช้รายการ `id` เดียวกันและน้ำหนักเดียวกันทั้งหมด ไม่เอาคะแนนสรุปบนการ์ดของแต่ละคนมาเทียบโดยตรง
- ชุดสำรองที่ไม่ได้ถูกใช้บนการ์ดของคนหนึ่งอาจถูกเลือกใน VS หากเป็นชุดเดียวที่ทั้งคู่มีข้อมูล เช่น ใช้ V-Dem ทั้งซ้ายและขวาแทนการนำ V-Dem ของยุคเก่าไปเทียบกับ WGI ของยุคใหม่ คะแนนด้านเดียวกันใน VS จึงอาจต่างจากหน้าแฟ้มได้
- การระบุทิศที่เข้ากับนิยามตัวชี้วัดผ่าน `favorable` ทำเฉพาะตัวชี้วัดที่ให้คะแนนและ **ทั้งสองฝั่งมีฐาน `tenure` ซึ่งมีอย่างน้อยสองค่าจากปีเกินครึ่งปี** หากฝั่งหนึ่งเป็นปีเดียวหรือบริบทประเทศให้ค่านี้เป็น null แม้ยังคำนวณส่วนต่างได้ ไม่ประกาศผู้ชนะรวม
- สามารถระบุ “ค่าที่รายงานสูงกว่า/ต่ำกว่า” แต่ห้ามเปลี่ยนเป็น “บริหารดีกว่า” “เอาชนะ” หรือ “ทำให้เกิดผลนี้” โดยไม่มีงานประเมินที่รองรับ
- ค่า World (WLD) ที่เก็บใน `benchmark` เป็นบริบทในหน่วยเดียวกัน ใช้เฉพาะปีที่ทั้งข้อมูลไทยและโลกมีค่า อย่าเปรียบค่าเฉลี่ยไทย 5 ปีกับโลก 3 ปีแล้วเรียกว่าส่วนต่างในช่วงเดียวกัน ค่า World เป็น aggregate ของ World Bank ซึ่งอาจใช้วิธีถ่วงน้ำหนักต่างกันตามตัวชี้วัด ไม่ใช่ค่าเฉลี่ยแบบให้ทุกประเทศน้ำหนักเท่ากัน
- ไม่อ้างว่าหักค่าโลกแล้วควบคุมผลของวิกฤตได้หมด ตัวอย่างเช่นโครงสร้างการท่องเที่ยวไทยต่างจากโลกมากในช่วง COVID-19
- ปุ่มสุ่มคู่ทำได้เพื่อสำรวจข้อมูล แต่ไม่เลือกคู่หรือซ่อนตัวชี้วัดเพื่อเชียร์ฝ่ายหนึ่ง การแชร์คู่ควรคง person/term IDs และลิงก์วิธีคิด
- แสดงความครอบคลุมเป็นหลักฐาน เช่น จำนวนด้าน ตัวชี้วัดร่วม ปีที่มีค่า และป้ายฐานปี `coverage` คือจำนวนปีที่มีค่าหารด้วยจำนวนปีที่เข้าเกณฑ์ของฝั่งนั้น ไม่ใช่ระดับความมั่นใจทางสถิติ และจำนวนปีที่มีค่าไม่เท่ากับจำนวนการสำรวจอิสระ
- สนุกได้ด้วยการเปิดตัวสองการ์ด การสลับซ้ายขวา และหมวด “GDP / สุขภาพ / สิทธิ” โดยไม่เติมเสียงหรือประกาศ winner อัตโนมัติ

## ข้อจำกัดรายด้าน

### เศรษฐกิจและการค้า

GDP growth และ export growth เป็นอัตราเติบโตที่ปรับราคาคงที่ ไม่ใช่ยอดเงินปัจจุบัน อัตราเติบโตสูงหลังปีเศรษฐกิจหดตัวอาจสะท้อนฐานต่ำ ความผันผวนของเศรษฐกิจโลก ดอกเบี้ย ภัยธรรมชาติ และอุปสงค์ต่างประเทศมีผลต่อผลลัพธ์ นายกฯ รัฐบาล ธนาคารกลาง บริษัท แรงงาน และรัฐบาลก่อนหน้าต่างมีบทบาท GDP ต่อคนไม่ใช่ค่าจ้างและไม่บอกว่าใครได้รับรายได้เพิ่ม

ชุด Maddison Project เป็นประมาณการประวัติศาสตร์ GDP ต่อคนแบบ PPP เก็บระดับไว้เป็นบริบทเท่านั้น ส่วน growth คำนวณเฉพาะสองปีติดกันที่มีค่าจริงในต้นทาง จึงเริ่มปี 1951 และไม่สร้าง growth จากช่องว่างก่อนหน้า เก็บแยกจาก WDI และเลือกทั้งแหล่งตาม family ไม่ต่อค่าข้ามแหล่ง ดูสูตร นิยาม และหลักฐานไทยใน [historical-data.md](historical-data.md)

อ่านนิยามจาก [GDP growth](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/NY.GDP.MKTP.KD.ZG), [GDP per capita growth](https://data.worldbank.org/indicator/NY.GDP.PCAP.KD.ZG?locations=TH) และ [export growth](https://data.worldbank.org/indicator/NE.EXP.GNFS.KD.ZG?locations=TH)

### การคลัง

หนี้ชุดนี้เป็นรัฐบาลกลาง ไม่ใช่หนี้สาธารณะทั้งหมดที่สำนักงานบริหารหนี้สาธารณะไทยรายงาน หนี้เป็นยอดคงค้าง ณ เวลาอ้างอิง ต่างจาก GDP ซึ่งเป็นผลผลิตตลอดช่วงปี การเทียบต้องสนใจดอกเบี้ย โครงสร้างหนี้ สินทรัพย์ รายได้รัฐ และเหตุผลที่กู้ด้วย จึงไม่ทำคะแนนจาก “ยิ่งน้อยยิ่งดี” และไม่อ้างว่าหนี้เพิ่มในปีหนึ่งทั้งหมดเป็นผลจากคนที่ได้ปีนั้น

อ้างอิง [central government debt metadata](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/GC.DOD.TOTL.GD.ZS) และ [tax revenue](https://data.worldbank.org/indicator/GC.TAX.TOTL.GD.ZS?locations=TH)

### การศึกษา

Completion proxy ในชุดนี้นับผู้เข้าชั้นปีสุดท้ายครั้งแรก ไม่ได้ตรวจว่าทุกคนเรียนจนจบจริง ส่วน gross enrollment นับนักเรียนทุกวัย อัตราทั้งสองจึงเกิน 100% ได้จากคนต่างวัยและการเรียนซ้ำ ไม่ใช่เปอร์เซ็นต์เด็กวัยเรียนทุกคนที่สำเร็จการศึกษา ตัวเลขเหล่านี้ไม่ครอบคลุมทักษะอ่านเขียน คณิตศาสตร์ คุณภาพครู หรือการคิดวิเคราะห์ ทั้งสองชุดใช้เป็นบริบท ไม่ให้ดัชนี เพราะค่าที่สูงเกิน 100% ไม่ได้หมายถึงการเข้าถึงหรือคุณภาพที่ดีขึ้นเสมอ

**Net secondary enrollment** นับเฉพาะนักเรียนมัธยมที่มีอายุตามเกณฑ์เทียบประชากรวัยเดียวกัน จึงใช้เป็นมิติการเข้าถึงตามวัย ข้อมูลไทยมี 11 ปี ได้แก่ 1973–1974, 2006–2012 และ 2014–2015 วาระหลังปี 2015 ไม่มีข้อมูลจากตัวชี้วัดนี้ ไม่แทนด้วย gross หรือ completion proxy

เพิ่ม **จำนวนปีการศึกษาสะสม** จาก Lee–Lee อายุ 15–64 (ประวัติศาสตร์ทุกห้าปีถึง 2010) และ UNDP อายุ 25 ปีขึ้นไป (1990–2023) เป็นอนุกรมทางเลือกภายใน `education-attainment` แยกอายุ นิยาม และชื่อชัดเจน VS ต้องใช้อนุกรมเดียวกันทั้งสองฝั่ง ห้ามเทียบค่าของกลุ่มอายุต่างกันโดยตรงหรือเชื่อมปีของทั้งสองชุดเข้าด้วยกัน ค่ารายปีของ UNDP อาจผ่านการประมาณของต้นทาง ไม่ใช่สำรวจใหม่ทุกปี

เพิ่ม **สัดส่วนผู้ใหญ่อายุ 25 ปีขึ้นไปที่จบอย่างน้อยมัธยมปลาย** `SE.SEC.CUAT.UP.ZS` จาก UNESCO UIS/WDI ในกลุ่ม `education-completion` ต่างจากจำนวนปีเรียนและต่างจาก completion proxy ข้างต้น ตัวนี้วัดวุฒิการศึกษาที่ผู้ใหญ่ได้รับแล้ว รวมผู้ที่จบสูงกว่ามัธยมปลาย ไม่ใช่อัตราจบของนักเรียนในปีปัจจุบัน ใช้เป็นดัชนีได้ตามทิศสัดส่วนผู้ใหญ่ที่เรียนถึงระดับนี้สูงขึ้น

**Expected years of schooling** ของ UNDP แสดงบริบทเท่านั้น เพราะเป็นค่าคาดหมายตามการเข้าเรียนของปีอ้างอิงและรวมปีซ้ำชั้น จำนวนปีสูงขึ้นไม่ได้ดีขึ้นเสมอ ข้อมูลคาดหมายนี้ไม่ใช่การนำค่าพยากรณ์ปีอนาคตมาใส่เป็นผลที่เกิดแล้ว

ปีอ้างอิงของ UIS อาจเป็นปีที่สิ้นสุดปีการศึกษา ผลของการเรียนและวุฒิสะสมหลายปีไม่สามารถยกให้รัฐบาลปีท้ายเพียงปีเดียว ด้านการศึกษาครอบคลุมการเข้าถึงและการศึกษาที่สะสมมา ยังไม่ใช่ผลประเมินคุณภาพการเรียนครบมิติ ดูแหล่งและข้อจำกัดแต่ละชุดที่ [extended-data.md](extended-data.md)

อ้างอิง [completion metadata](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/SE.SEC.CMPT.LO.ZS), [gross enrollment metadata](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/SE.SEC.ENRR) และ [net enrollment metadata](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/SE.SEC.NENR)

### สุขภาพและโครงสร้างพื้นฐาน

อายุคาดเฉลี่ยเป็นการคาดอายุตามแบบแผนการตายในช่วงอ้างอิง ไม่ใช่อายุเฉลี่ยคนที่ตายจริง ค่าตายทารกใช้การประมาณจาก UN IGME การเพิ่มอายุคาดเฉลี่ยและลดอัตราตายสะสมจากบริการและเงื่อนไขสังคมหลายทศวรรษ จึงได้ประโยชน์จากแนวโน้มระยะยาวเมื่อเปรียบระดับข้ามยุค

ชุดอายุขัยย้อนหลังเพิ่มข้อมูลไทยก่อน WDI แต่ต้นทางมีเพียงสี่จุดก่อน 1950 แล้วจึงต่อเนื่องรายปีตั้งแต่ 1950 มีรอยต่อวิธีประมาณระหว่างแหล่ง ไม่เติมปีที่หาย ไม่คำนวณความเปลี่ยนแปลงข้ามรอยต่อแล้วอ้างว่าเป็นผลนโยบาย เลือกทั้ง WDI หรือชุดย้อนหลังหนึ่งชุดใน family อายุขัยเพื่อไม่ให้น้ำหนักซ้ำ แหล่งรายจุดอยู่ใน [extended-data.md](extended-data.md)

อินเทอร์เน็ตมีเทคโนโลยีและภาคเอกชนเป็นแรงขับสำคัญ การเข้าถึงไฟฟ้าเมื่อใกล้ 100% มีเพดานและไม่บอกคุณภาพบริการ ค่าไฟ หรือความถี่ไฟดับ ใช้ระดับตัวชี้วัดเดียวกันเปรียบเทียบได้ในเชิงนิยาม แต่ไม่ได้ทำให้การแข่งขันข้ามยุคยุติธรรม

อ้างอิง [life expectancy](https://data.worldbank.org/indicator/SP.DYN.LE00.IN?locations=TH), [infant mortality](https://data.worldbank.org/indicator/SP.DYN.IMRT.IN?locations=TH), [internet use](https://data.worldbank.org/indicator/IT.NET.USER.ZS?locations=TH), [electricity access](https://data.worldbank.org/indicator/EG.ELC.ACCS.ZS?locations=TH)

### ความเหลื่อมล้ำและความยากจน

Gini ในชุดนี้มาจากข้อมูลสำรวจรายได้หรือการบริโภค ไม่ใช่การกระจายความมั่งคั่งที่รวมที่ดินและทรัพย์สินทุกประเภท บางปีไม่มีการสำรวจ ความต่างของวิธีสำรวจและฐานการวัดอาจทำให้เปรียบเทียบไม่ตรง ค่าเพียงปีเดียวแสดงตำแหน่งของค่านั้นในชุดอ้างอิงได้พร้อมป้าย แต่ใช้สรุปแนวโน้มไม่ได้ แม้มีหลายค่าก็ไม่รับประกันความเป็นตัวแทนของทั้งวาระ

เส้นความยากจนไทยใช้เกณฑ์ของประเทศ ซึ่งเทียบตรงกับเปอร์เซ็นต์ความยากจนของประเทศอื่นไม่ได้ ชุด `SI.POV.NAHC` ถูกแยกโดย World Bank จากชุดที่รวมค่าซึ่งไม่เทียบกันตามเวลา PMfolio ยังไม่ได้ตรวจการเปลี่ยนฐานสำรวจรายวาระกับเอกสารไทยครบถ้วน จึงเก็บเป็นบริบทและยังไม่ให้คะแนน

อ้างอิง [Gini](https://data.worldbank.org/indicator/SI.POV.GINI?locations=TH) และ [คำอธิบายชุดเส้นความยากจนแห่งชาติของ World Bank](https://blogs.worldbank.org/en/opendata/relative-versus-absolute-poverty-headcount-ratios-full-breakdown)

### สิ่งแวดล้อม

PM2.5 คือ exposure รายปีที่ถ่วงตามประชากรและใช้แบบจำลองร่วมกับสถานีและข้อมูลดาวเทียม ไม่ใช่ค่าตรวจวัดทุกสถานีที่นำมาเฉลี่ยตรง ๆ จึงควรดูแนวโน้มและความเสี่ยงการสัมผัส ไม่ใช้แทนการบังคับใช้มาตรฐานรายวัน ค่าของไทยยังได้รับผลจากฤดูกาล อากาศ และฝุ่นข้ามพรมแดน

CO₂ ต่อคนไม่รวมการใช้ที่ดิน การเปลี่ยนการใช้ที่ดิน และป่าไม้ (LULUCF) และไม่รวมก๊าซเรือนกระจกชนิดอื่นเป็นยอดทั้งหมด ประเทศที่ผลิตเพื่อส่งออกมากอาจมีการปล่อยสูงกว่าประเทศที่บริโภคสินค้านำเข้า การปล่อยลดลงในวิกฤตเศรษฐกิจไม่ใช่หลักฐานว่านโยบายสีเขียวประสบความสำเร็จ

อ้างอิง [PM2.5 metadata](https://databank.worldbank.org/metadataglossary/world-development-indicators/series/EN.ATM.PM25.MC.M3) และ [CO₂ metadata](https://data360files.worldbank.org/data360-data/metadata/WB_WDI/WB_WDI_EN_GHG_CO2_PC_CE_AR5.pdf)

### ธรรมาภิบาลและสิทธิเสรีภาพ

ใช้ WGI **2026 update** source ID `3` และรหัส `GOV_WGI_VA.SC` / `GOV_WGI_CC.SC` ซึ่งเป็นมาตรา absolute 0–100 ของชุดปรับวิธี ไม่ใช้ `VA.EST` / `CC.EST` รุ่นเก่าที่อยู่ใน WDI archives มาตรา WGI ดิบและ percentile ของ PMfolio เป็นคนละอย่าง ต้องแยกชื่อให้ชัด

Voice and Accountability รวมมุมมองเรื่องการมีส่วนร่วมเลือกผู้ปกครอง เสรีภาพการพูด การรวมตัว และสื่อ ไม่ใช้ความสงบหรืออายุรัฐบาลแทนสิทธิของประชาชน Control of Corruption วัดการรับรู้เรื่องการใช้อำนาจเพื่อประโยชน์ส่วนตัว ไม่ใช่คำตัดสินความผิดของบุคคลใด

WGI มีข้อมูลรับรู้จากการสำรวจและผู้เชี่ยวชาญ มีความไม่แน่นอนและผลที่รับรู้ล่าช้า ต้นทางกำหนดช่วงความเชื่อมั่น 90% ซึ่งเก็บไว้ใน `uncertainty` ตามปีจากรหัสที่ลงท้าย `.SC_LB` / `.SC_UB` ความต่างของคะแนนเล็กน้อยหรือช่วงที่ทับกันไม่อาจสรุปนัยสำคัญทางสถิติโดยดูค่าเฉลี่ยอย่างเดียว การเฉลี่ยขอบช่วงของหลายปีไม่ใช่ช่วงความเชื่อมั่นของค่าเฉลี่ยวาระ จึงไม่สร้างช่วงรวมโดยไม่มีแบบจำลองความสัมพันธ์ระหว่างปี

ข้อมูลปี 1997, 1999 และ 2001 ไม่มีค่าใน API snapshot นี้ ไม่เติมค่าระหว่างปี รุ่นใหม่คำนวณประวัติย้อนหลังตามวิธีที่ปรับแล้ว จึงห้ามต่ออนุกรมกับคะแนนรุ่นเดิมเพื่อขยายความยาว

เพิ่ม **V-Dem Electoral Democracy Index v16 (2026)** เป็นทางเลือกย้อนหลังของกลุ่ม `civic-rights` มีค่าประมาณไทยปี 1932–2025 ค่าดิบ 0–1 วัดสถาบันการเมืองตามนิยามประชาธิปไตยด้านการเลือกตั้ง ไม่ใช่คะแนนทักษะนายกฯ และไม่ครอบคลุมธรรมาภิบาลทุกมิติ จัด priority ต่ำกว่า WGI Voice and Accountability แต่ยังเปิดค่าดิบของทั้งสองชุดได้ VS เลือกเพียงแหล่งเดียวที่ทั้งคู่มีค่า ไม่เปรียบข้ามมาตราและไม่ต่ออนุกรมเข้าด้วยกัน

V-Dem ใช้การประเมินผู้เชี่ยวชาญและแบบจำลอง จึงมีความไม่แน่นอน Snapshot นี้เก็บเฉพาะค่ากลาง ไม่ได้เก็บช่วงความไม่แน่นอนของ V-Dem และห้ามนำป้ายช่วงความเชื่อมั่น 90% ของ WGI ไปใช้กับชุดนี้ รายละเอียดรุ่น นิยาม และเงื่อนไข CC BY-SA 4.0 อยู่ที่ [extended-data.md](extended-data.md)

อ้างอิง [WGI current release และ usage advisory](https://www.worldbank.org/en/publication/worldwide-governance-indicators), [WGI documentation](https://www.worldbank.org/en/publication/worldwide-governance-indicators/documentation) และ [รายการรหัสปัจจุบันจาก source 3 API](https://api.worldbank.org/v2/source/3/indicator?format=json&per_page=500)

## สิ่งที่ยังไม่ครอบคลุม

สถิติเหล่านี้ยังไม่ครอบคลุมคุณภาพการเรียนรู้ เช่น PISA, ความสามารถอ่านเขียนในช่วงก่อนมีชุดสำรวจ, ประสิทธิภาพการใช้จ่ายรัฐ, ความปลอดภัย, ภาระค่าครองชีพรายครัวเรือน, ประสิทธิภาพกระบวนการยุติธรรม, ความมั่นคงเชิงสิทธิ, ผลตอบแทนโครงการลงทุน หรือความรับผิดชอบต่อเหตุการณ์เฉพาะเรื่อง

การเพิ่มคะแนนจากงานวิจัยคุณภาพหรือนโยบายเฉพาะด้านต้องมีหน่วย นิยาม ช่วงเวลา วิธีสำรวจ และเกณฑ์ที่ตรวจได้ก่อน ห้ามเปลี่ยนข้อเล่าประวัติศาสตร์เป็นคะแนน 0–100 โดยไม่ประกาศ rubric และผู้ประเมิน และห้ามทำให้ไม่มีข้อมูลดูเหมือนผลลัพธ์แย่

การปรับข้อมูลครั้งต่อไปต้องตรวจทั้ง source revision และผลต่อดัชนี ตรวจการนับวัน/ปี การตัดปีปัจจุบัน กติกาปีเดียวกับฐานอ้างอิงอย่างน้อยสองปี การเปิดบริบทเฉพาะกรณีไม่มีปีเกินครึ่งปี การไม่ยืมปีที่ขาด การเลือกหนึ่งอนุกรมต่อ family และชุดร่วมของ VS รวมถึงการไม่ระบุ `favorable` สำหรับปีเดียวหรือบริบท จาก unit/data tests ก่อน build และเผยแพร่
