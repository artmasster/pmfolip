# PMfolio visual direction

Approved by the owner on 3 October 2026: **character roster × public archive**, using the previously generated [visual direction board](brand-direction.png).

Brand: **PMfolio**, from Prime Minister + Portfolio. Tagline: **Every term. On record. / ทุกวาระ มีหลักฐาน**. Published at **https://artmasster.github.io/pmfolip/**. The repository spelling is intentional and differs from the brand.

## Visual language

Warm paper `#F1EDE3`, midnight ink `#14282C`, acid lime `#D4F77D` and steel `#A1B7BC`. Barlow Condensed display type, Playfair Display wordmark, IBM Plex Sans Thai body and IBM Plex Mono metadata. The roster gives every leader the same portrait treatment and card structure; accent color denotes selection and datasets, never party affiliation or personal quality.

Use real attributed portraits with presentation-only CSS grayscale/halftone. The approved board's illustrated portraits and demo numbers are design references only, never factual site assets or source data. Fine rules, clipped card corners, compact archival labels and restrained motion establish the archive identity.

## VS interaction

The owner requested an interesting VS gimmick in the same task. Delivered direction: a comparison room with two selected records, lime/steel sides, per-period selection, overlapping radar for common scorable categories, animated stat-bar changes, raw values and cited historical records. Random pairs select two distinct leaders with data; share URLs preserve the pair and period choices. Comparison avoids a fabricated overall victor.

Shared UI controls are mandatory; components live in `src/components/ui`. Keyboard focus returns when dialogs close. Automatic motion respects reduced-motion preferences. Ordinary UI work is verified without browser screenshots unless the owner requests them.
