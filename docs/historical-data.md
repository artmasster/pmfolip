# GDP ย้อนหลังของไทยจาก Maddison Project

สถานะ: active · ข้อมูลสำหรับ PMfolio · ตรวจแหล่งต้นทาง 3 ตุลาคม 2026

## แหล่งข้อมูลและสิทธิการใช้

ไฟล์ [historical-indicators.json](../src/data/historical-indicators.json) มาจาก [Maddison Project Database 2023 ของ University of Groningen](https://www.rug.nl/ggdc/historicaldevelopment/maddison/releases/maddison-project-database-2023) เผยแพร่ 26 เมษายน 2024 ที่ [DataverseNL, DOI 10.34894/INZBF2](https://doi.org/10.34894/INZBF2) ไม่ใช่ตัวเลขที่ PMfolio ประเมินบุคคลเอง

เจ้าของชุดข้อมูล: Jutta Bolt และ Jan Luiten van Zanden (2024). วิธีวิจัย: [Maddison style estimates of the evolution of the world economy: A new 2023 update](https://doi.org/10.1111/joes.12618). ใช้ภายใต้ [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). PMfolio คัดข้อมูลไทยและเพิ่มตัวแปรการเติบโตตามสูตรด้านล่าง ชุดข้อมูลไม่ได้รับรอง PMfolio หรือการจัดคะแนนนายกรัฐมนตรี

ตามข้อกำหนดการอ้างอิง ต้องระบุงานต้นทางของประเทศเมื่อแสดงกราฟหรือเลือกประเทศจำนวนน้อย แผ่น `Maddison original sources` ระบุข้อมูลไทยช่วง 1900–1950 จาก Sompop Manarungsan (1989), *Economic Development of Thailand, 1850–1950*, วิทยานิพนธ์ University of Groningen. แผ่น `Sources` ระบุแหล่งช่วง 2008–2022 เป็น Total Economy Database ของ Conference Board และ UN National Accounts ตามประเทศที่ครอบคลุม ช่วงก่อนหน้านั้นสืบทอดประมาณการ Maddison และการปรับ benchmark ตามบทความข้างต้น ไม่อ้างว่าผู้จัดทำ PMfolio ตรวจเอกสารบัญชีไทยแต่ละปีด้วยตนเอง

## ความครอบคลุมที่ตรวจพบจริง

อนุกรมที่เก็บเริ่มปี 1913 ประกอบด้วย **1913, 1929, 1938 และทุกปี 1950–2022** รวม 76 จุดข้อมูล ปี 1913 และ 1929 มีไว้เป็นบริบทก่อนมีตำแหน่งนายกรัฐมนตรีไทย ไม่ใช้ย้อนไปให้คะแนนนายกรัฐมนตรีคนแรก

ข้อมูลก่อนปี 1950 ไม่ต่อเนื่อง: ในยุคนายกรัฐมนตรีไทยก่อนปี 1950 มี GDP ต่อคนเพียงปี **1938** จึงไม่สามารถสร้างอัตราเติบโต 1932–1949 หรือให้คะแนนเศรษฐกิจครบทุกรัฐบาลได้โดยอาศัย MPD ชุดนี้ ไม่เติมค่าระหว่างจุดและไม่แทนช่องว่างด้วยศูนย์

ค่าประเมินตัวอย่างในไฟล์ต้นทาง: GDP ต่อคนปี 1938 = 1,317; ปี 1950 = 1,302; ปี 1951 = 1,353 ดอลลาร์สากลราคาปี 2011 ต่อคน เหล่านี้เป็นระดับผลผลิตต่อคนที่ปรับ PPP ไม่ใช่ค่าจ้าง รายได้ครัวเรือน หรือดอลลาร์สหรัฐราคาปัจจุบัน

## ตัวชี้วัดและการใช้คะแนน

| ตัวชี้วัด | ข้อมูลที่ใช้ | การตีความ |
|---|---|---|
| `historical-gdp-per-capita` | ระดับ GDP ต่อคนตาม MPD, 76 จุด | บริบทเท่านั้น `scorable: false`; ไม่แปลงระดับรายได้ข้ามยุคให้เป็นทักษะนายกรัฐมนตรี |
| `historical-gdp-per-capita-growth` | `(gdppc[t] / gdppc[t−1] − 1) × 100`, เฉพาะสองปีติดกันที่ต้นทางมีค่าจริง | 72 ค่า ปี 1951–2022; ผลลัพธ์ทางเศรษฐกิจช่วงปี ไม่ใช่ผลเชิงเหตุและผลของรัฐบาล |

ไม่มี growth ปี 1938 หรือ 1950 เพราะต้นทางไม่มีปีฐานก่อนหน้าติดกัน จึงไม่หารความต่างหลายปีแล้วเรียกว่าอัตราเติบโตรายปี และไม่สร้างค่ารายปีจากการลากเส้นระหว่างจุด

ทั้งระดับและ growth อาศัย **ประมาณการประวัติศาสตร์ของนักวิจัย** ไม่ได้หมายความว่ามีการสำรวจภาคสนามโดยตรงครบทุกปี บทความ MPD อธิบายการปรับ benchmark ของ PPP และข้อจำกัดข้อมูลเศรษฐกิจในอดีต การใช้สองปีติดกันในสคริปต์เพียงยืนยันว่ามีค่ารายปีในต้นทาง ไม่ยืนยันว่าไม่มีสมมติฐานหรือการประมาณในกระบวนการของต้นทาง

เก็บแยกอนุกรมจาก WDI ทั้งหมด หน่วยและนิยามของระดับ PPP ไม่ใช่ growth ของ WDI; อัตราเติบโตที่คำนวณจาก MPD ก็อาจต่างจาก WDI จากการสร้างอนุกรมและ revision

`scoreFamily: gdp-per-capita-growth` และ `scorePriority: 10` เป็นกติกาป้องกันการนับ GDP ต่อคนซ้ำกับ WDI ซึ่งได้ลำดับสูงกว่า เลือกแหล่งเดียวตามเงื่อนไขใน [methodology.md](methodology.md) แต่ยังเปิดค่าดิบทั้งสองให้ตรวจได้ การเทียบ VS ต้องใช้ indicator เดียวกันทั้งคู่และไม่ผสม MPD ของคนหนึ่งกับ WDI ของอีกคน

## ทำซ้ำและตรวจความถูกต้อง

[fetch-historical-indicators.py](../scripts/fetch-historical-indicators.py) ใช้ Python standard library ดาวน์โหลด metadata และ [Excel ต้นทาง](https://dataverse.nl/api/access/datafile/421302) โดยไม่มี token ไม่เขียนไฟล์เอง และไม่ใช้ snapshot เก่าเมื่อดาวน์โหลดพัง

```bash
python3 scripts/fetch-historical-indicators.py --as-of 2026-10-03
python3 scripts/fetch-historical-indicators.py --as-of 2026-10-03 --patch
```

คำสั่งแรกพิมพ์ JSON คำสั่งที่สองพิมพ์ patch สำหรับตรวจและใช้ผ่าน apply_patch วัน `asOf` เป็นวันที่ดึงข้อมูล ไม่ใช่ปีล่าสุดของตัวเลข และไม่สามารถร้องขอ vintage ก่อนชุดข้อมูลเผยแพร่ได้

สคริปต์ตรวจรหัสประเทศ `THA`, ชื่อ Thailand, หน่วยบนหัวตาราง, รายการปีครบตาม release ที่ทบทวน, ค่าบวกและ finite, แหล่งอ้างอิงไทย และ checksum SHA-1 ทั้งใน Dataverse metadata และไฟล์จริง: `1480521f602fbd5df64e108867ac971caa00ed1a`. หากต้นทางเปลี่ยนไฟล์ สคริปต์หยุดให้ตรวจ revision ก่อน ไม่รับชุดใหม่เงียบ ๆ. Parse ค่าใน workbook โดยไม่รันสูตรและไม่ extract ไฟล์ลงระบบไฟล์

เมื่อเปลี่ยนข้อมูลให้ตรวจสูตร growth กับค่าต้นทาง ตรวจว่าไม่มีค่าของปีที่หาย แล้วทำ release checks ตาม [development.md](development.md)
